🎯 Today's Big Idea

🍕 Imagine a university pizza shop!

You have 30 rupees for a pizza and 20 rupees for a drink. You add them to find the bill. Then you ask questions: “Is the bill at least ₹50?” “Did the student pay enough?” “Are both conditions true?” Operators are the tiny symbols that help Java perform these actions.
ELI10: Operators are like the tools in a kitchen: ➕ add ingredients, ➖ remove ingredients, 🔍 compare ingredients, 🧠 combine conditions, 🔄 change quantities, and ❓ choose between two outcomes.

☕ 9. Complete UniFlow Examination Program

public class ExaminationManagement {

  public static void main(String[] args) {

    int internalMarks = 22;
    int externalMarks = 28;

    int totalMarks = internalMarks + externalMarks;

    System.out.println("Total >= 50: " + (totalMarks >= 50));
    System.out.println("Internal >= 20: " + (internalMarks >= 20));
    System.out.println("External >= 30: " + (externalMarks >= 30));

    boolean eligible = totalMarks >= 50 && externalMarks >= 30;
    System.out.println("Eligible before grace: " + eligible);

    totalMarks += 5;

    String result =
        (totalMarks >= 50 && externalMarks >= 30)
        ? "Pass" : "Fail";

    System.out.println("Updated Total: " + totalMarks);
    System.out.println("Result: " + result);
  }
}
