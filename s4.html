🎯 Today's Big Question

ELI10: How does a Java program go from something we type on the keyboard to something the computer can actually run?
Imagine writing a letter in English. The computer's JVM does not directly execute your Java source code. Java first turns the source into bytecode, and then the JVM runs that bytecode.

Java idea: Write Once → Compile → Run Anywhere there is a compatible JVM.

🌍 3. What Does “Write Once, Run Anywhere” Mean?

☕ Java Source
↓
📦 Bytecode

One .class file

🪟 Windows JVM
🍎 macOS JVM
🐧 Linux JVM
ELI10: Think of bytecode as a common language. Windows, macOS and Linux can each have a JVM that understands that common language. So the same compiled Java bytecode can run on different systems.

Important: “Write Once, Run Anywhere” does not mean Java never needs compilation. Normally, you compile the source into bytecode first, then run that bytecode with a suitable JVM.

🧪 10. Quick Student Challenge

Q1. Which tool converts .java into .class?

⚙️ javac — the Java compiler.

Q2. What does the JVM execute?

📦 Java bytecode stored in the .class file.

Q3. Where does Java start executing a normal standalone application?

☕ The main() method.

Q4. Does a comment produce an output?

❌ No. Comments are for humans and are ignored by the compiler as program instructions.

Q5. What is the final output after modifying the program?
