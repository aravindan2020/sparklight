ELI10 Guide for Beginner Students

🔍 Don't just use security tools — learn how to discover new security knowledge!

🤔 1. What is Cybersecurity?

🤖 Imagine this:

You have a house. Your house contains your books, money, laptop and important documents.

You use:
  • 🔑 Lock → Password
  • 🚪 Door → Firewall
  • 📹 CCTV → Monitoring
  • 🚨 Alarm → Intrusion Detection
  • 🛡️ Security Guard → Security System
Cybersecurity does the same thing for computers and networks.

🔬 2. What is Cybersecurity Research?

Research = Asking a good question + investigating it + finding evidence + proposing an improvement.

Cybersecurity research is NOT simply learning how to use Kali Linux, Nmap or Wireshark.

Research means asking:

❓ "Can I find a better way to detect an attack?"
❓ "Can I reduce false alarms in an Intrusion Detection System?"
❓ "Can Machine Learning identify vulnerable source code?"
❓ "Can blockchain improve trust between IoT devices?"

⚔️ 3. Cybersecurity Practice vs Research

Cybersecurity Practice Cybersecurity Research
Use Nmap to scan a network Develop a better method to identify suspicious network behaviour
Use Wireshark to capture packets Study traffic patterns to detect attacks automatically
Run vulnerability scanners Develop a technique to detect previously unknown weaknesses
Configure a firewall Compare different firewall strategies
Use an IDS Improve IDS detection accuracy
💡 Remember: Using a tool is not automatically research. Studying a problem and producing new evidence or improvement is research.

🕵️ 4. Think Like a Cybersecurity Detective

Imagine you are Detective Cyber.

🕵️ Problem: Many students receive phishing emails.

🔍 Observation: Some emails contain suspicious links.

❓ Research Question: Can machine learning identify phishing emails?

🧪 Experiment: Give an ML model many phishing and legitimate emails.

📊 Measure: Accuracy, precision, recall and false positives.

💡 Conclusion: Find out whether the proposed method works better.

🧪 8. Example Research Problem

Problem: Phishing Email Detection

Step 1 — Problem
People receive fake emails.

Step 2 — Question
Can machine learning identify fake emails?

Step 3 — Data
Collect legitimate and phishing email datasets.

Step 4 — Features
Study URL length, suspicious words, sender information, etc.

Step 5 — Model
Train a machine-learning classifier.

Step 6 — Evaluation
Measure accuracy, precision, recall and F1-score.

🕳️ 10. What is a Research Gap?

Imagine 10 students build bridges.

🏗️ Researchers already built bridges that are:
  • Strong
  • Cheap
  • Fast
But nobody studied:
"Can we build a bridge that is both cheap AND extremely fast?"
That missing part is similar to a research gap.
Existing Research What is Missing? Your Opportunity
Method A has high accuracy Uses high computation Develop lightweight method
Method B is fast Low detection accuracy Improve accuracy
Method C detects attacks Many false alarms Reduce false positives

📊 12. How Do Researchers Know If Their Idea Works?

Metric ELI10 Meaning Example
Accuracy How many predictions were correct? 95 correct out of 100
Precision When we say "attack", how often are we correct? 90% of detected attacks are real
Recall How many real attacks did we find? 92 out of 100 attacks detected
F1-Score Balance between precision and recall Useful for imbalanced datasets
Execution Time How fast is the method? 2 seconds
False Positive Alarm says attack, but it isn't Normal user marked as attacker

🤖 13. How Can Students Use AI in Research?

AI can be your research assistant, not your research replacement.
Good Use Bad Use
Ask AI to explain a paper Copy an entire paper
Ask for research questions Accept every idea without checking
Ask AI to explain code Submit AI code without understanding it
Ask AI to find bugs Assume AI is always correct
Ask AI to compare algorithms Invent experimental results
🎯 Golden Rule: Ask AI → Understand → Verify → Modify → Experiment → Defend
