🚀 Programming for Problem Solving with Java

Session 1: From a Real University Problem → Thinking → Algorithm → Java Program

🎯 What are we learning today?

ELI10: Imagine your university is a huge school. Thousands of students need admission, courses, attendance, marks and reports. Instead of managing everything with notebooks, we want to build one smart computer system called UniFlow.

Java is the tool. Problem-solving is the skill. UniFlow is our real-world project.

🏫 Meet UniFlow

Imagine this: A student joins the university. First, we collect admission details. Then the student registers for courses. Every day, attendance is recorded. Later, marks are entered. Finally, the system prepares results and academic reports.

The UniFlow journey

1. Student AdmissionRegister a new student.
2. Course RegistrationChoose and register courses.
3. AttendanceRecord daily attendance.
4. ExaminationStore and process marks.
5. Result ProcessingCalculate totals, averages and results.
6. ReportsCreate useful academic reports.

🧩 Why do we need Problem Solving?

Computers are very good at following instructions, but they cannot magically understand a messy real-world problem.

ELI10 example: If I say, “Manage all students,” the computer asks: Which students? What information? What rules? What should I do with the information? What should I show?

So we first convert a big problem into small, clear problems.

🧠 Computational Thinking

Computational thinking means thinking like a problem-solving computer scientist before writing code.

🧱

1. Decomposition

Break one big problem into smaller pieces.

UniFlow: Admission → Registration → Attendance → Examination → Reports

🔍

2. Pattern Recognition

Find things that happen again and again.

Example: Many modules need student ID and student name.

🎯

3. Abstraction

Focus on important information and ignore unnecessary details.

Example: Admission needs a mobile number, but may not need the student's favorite color.

📋

4. Algorithmic Thinking

Arrange the solution as clear step-by-step instructions.

Example: Read ID → Check ID → Read mobile → Check mobile → Accept or reject.

🔄 The IPO Model

ELI10: Think about a sandwich machine. You give it ingredients (Input), it makes the sandwich (Process), and you receive the sandwich (Output).
INPUT
⬇Information we give
PROCESS
⚙️Rules + calculations
OUTPUT
⬇Result we get

UniFlow example

Input: Student ID, Name, Department, Mobile Number

Process: Check whether ID is unique and mobile number has exactly 10 digits.

Output: Admission successful OR an error message.

🧪 Try the Thinking Challenge

Question 1: Student ID “24CSE101” is already stored. What should happen?

❌ Reject the admission because Student ID must be unique.

Question 2: Mobile number is “987654321”. What should happen?

❌ Reject it because it contains only 9 digits.

Question 3: Mobile number is “9876543210” and Student ID is unique. What should happen?

✅ Admission can be accepted, assuming the other required details are valid.
