⚠️ 6. The Most Important Example: Average

22 + 29
➡️
51
➡️
÷ 2
➡️
25 ❌

Why 25? Because both operands are integers:

int internalMarks = 22;
int externalMarks = 29;
double average = (internalMarks + externalMarks) / 2;

The addition gives 51. Then 51 / 2 is integer division, producing 25. The result is then assigned to double as 25.0.

Correct approach: Make one operand a double before division.
double average = (internalMarks + externalMarks) / 2.0;
Correct average = 25.5

☕ 8. Complete UniFlow Examination Program

public class ExpressionEvaluation {

  public static void main(String[] args) {

    int internalMarks = 22;
    int externalMarks = 29;

    int totalMarks = internalMarks + externalMarks;

    double averageAutomatic = totalMarks / 2.0;
    int averageInteger = totalMarks / 2;
    int averageCast = (int) averageAutomatic;

    System.out.println("Internal Marks : " + internalMarks);
    System.out.println("External Marks : " + externalMarks);
    System.out.println("Total Marks : " + totalMarks);
    System.out.println("Average (double): " + averageAutomatic);
    System.out.println("Average (int) : " + averageInteger);
    System.out.println("Average cast : " + averageCast);

    System.out.println("Without casting: " + (internalMarks + externalMarks) / 2);
    System.out.println("With casting : " + (double)(internalMarks + externalMarks) / 2);

  }
}

🧪 13. Quick Robot Challenge

Q1. What is 51 / 2 when both are int?

🤖 25 — integer division discards the decimal portion.

Q2. What is 51 / 2.0?

🤖 25.5 — the presence of a double causes floating-point division.

Q3. What is (int)25.9?

🤖 25 — explicit cast to int removes the fractional part; it does not round to 26.

Q4. Why is (double)(51 / 2) still 25.0?

🤖 Because 51 / 2 is calculated first as integer division. Only the final 25 is then converted to double.

Q5. Which is better for an average: /2 or /2.0?

🤖 /2.0 when a decimal average is required.
