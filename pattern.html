Star Pattern Notes

Follow the same thinking used in the classroom: Pattern Diagram → n, i, s, j Tabulation → Java Program. Every row begins with i = 0. Derive s and j from i and n instead of memorising patterns.

How to Read the Tabulation

n = total size   |   i = row number starting at 0   |   s = spaces before the pattern   |   j = number of stars/elements printed.

Step 1Take n = 5.
Step 2Start i = 0 and increase row by row.
Step 3Derive s from i and n.
Step 4Derive j from i and n.

int i, s, j;

for (i = 0; i < n; i++) {
    s = 0;
    j = i + 1;

    for (int k = 0; k < s; k++)
        System.out.print(" ");

    for (int k = 0; k < j; k++)
        System.out.print("* ");

    System.out.println();
}


Tabulation → Program: The program first derives s and j for the current i, then the loops directly use those values.

③ Program in Java


int n = 5;
int i, s, j;

for (i = 0; i < n; i++) {
    s = n - i - 1;
    j = i + 1;
    int value = 1;

    for (int k = 0; k < s; k++)
        System.out.print(" ");

    for (int k = 0; k < j; k++) {
        System.out.print(value + " ");
        value = value * (i - k) / (k + 1);
    }

    System.out.println();
}
