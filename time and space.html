Time and Space Complexity

Learn with Panda and Rabbit — a simple ELI10 conversation for beginner programmers.

🐼 Panda The coding buddy
Hi, Rabbit! Today we are learning how to check whether a program is efficient. We will look at time complexity and space complexity.
🐰 Rabbit
Efficient? Does that mean the program should finish quickly?
🐼 Panda
Yes! But there is another question too: how much memory does the program need? Imagine packing for a trip. We care about how quickly we finish packing and how much space our bags need.
🐰 Rabbit
So, are time and space two different things?
🐼 Panda
Exactly! Time complexity describes how the amount of work grows when the input gets bigger. Space complexity describes how the extra memory used by the program grows.
🐰 Rabbit
Can you give me an easy example?

⏱️ Time Complexity = Steps

How does the number of steps grow as the input becomes bigger?

🧠 Space Complexity = Memory

How does the extra memory needed grow as the input becomes bigger?
Think about finding a name in a list.
If you check names one by one, a longer list may require more checks. That is growing work — time complexity.
Think about storing marks.
If you create an array to store one mark for every student, more students means more memory — space complexity.
🐼 Panda
Suppose there are 5 student names. If I check every name one by one, I may do up to 5 checks. If there are 100 names, I may do up to 100 checks.
🐰 Rabbit
So the work grows with the number of names. Is that O(n)?
🐼 Panda
Correct! We call that O(n), read as “Big O of n”. Here, n means the input size — the number of names.
🐰 Rabbit
What about O(1)?
🐼 Panda
Imagine opening a numbered drawer directly. If you access a known array position, such as marks[2], the access takes a constant amount of work. We describe it as O(1).
🐰 Rabbit
Can a loop ever be O(1)?
🐼 Panda
Yes! Look at this loop. It always runs exactly 5 times. Its number of steps does not grow with the input size, so it is O(1).

Example: A fixed loop

for (int i = 1; i <= 5; i++) { System.out.println(i); }

Panda says: “The loop runs 5 times every time. Five is a fixed number, so the time complexity is O(1).”

Rabbit asks: “What if we change 5 to n?”

for (int i = 1; i <= n; i++) { System.out.println(i); }

Now the loop runs n times. If n becomes larger, the work increases. Its time complexity is O(n).

Common time complexities

These describe how the amount of work can grow as the input size increases.

Big-OSimple meaningExample idea
O(1)Constant — stays about the sameAccess an array element by index
O(log n)Logarithmic — reduce the problem repeatedlyBinary search in a sorted array
O(n)Linear — grows with the inputVisit every element once
O(n log n)Common efficient sorting growthMerge sort
O(n²)Quadratic — compare many pairsTwo nested loops, each running n times
O(2ⁿ)Exponential — grows very quicklyExplore all yes/no combinations

These are growth patterns, not exact running times in seconds.

How much memory? — Space complexity

🐰 Rabbit
If time complexity is about steps, how do I understand space complexity?
🐼 Panda
Imagine keeping student marks. If you store just one running total, you use a fixed amount of extra memory: O(1).
🐼 Panda
If you create an array to store n marks, the memory grows with n: O(n).
// A fixed number of variables: O(1) extra space int total = 0; int count = 0; // An array that grows with n: O(n) extra space int[] marks = new int[n];

Remember: Space complexity often focuses on the extra memory used by the algorithm. The input storage itself may be discussed separately.

🧩 Practice Time! — 15 O(1) Exercises

🐰 Rabbit: “Can I have some practice problems, Panda?”

🐼 Panda: “Of course! For every exercise, check whether the amount of work stays fixed, even when the input size changes.”

Important rule: A loop can be O(1) when it runs a fixed number of times that does not depend on the input size. The work inside each iteration must also be constant.

Part A — Six exercises using for and while loops

Each loop below has a fixed number of iterations, so each has O(1) time complexity.

1. Print numbers using for
for (int i = 1; i <= 5; i++) {
    System.out.println(i);
}

How many times does the loop run?

2. Sum numbers using for
int sum = 0;
for (int i = 1; i <= 5; i++) {
    sum += i;
}
System.out.println(sum);

Why does the work stay fixed?

3. Multiplication table using for
for (int i = 1; i <= 5; i++) {
    System.out.println(7 * i);
}

How many results are printed?

4. Print numbers using while
int i = 1;
while (i <= 5) {
    System.out.println(i);
    i++;
}

Does the loop depend on n?

5. Factorial of fixed 5 using while
int fact = 1;
int i = 1;
while (i <= 5) {
    fact *= i;
    i++;
}
System.out.println(fact);

What changes if 5 becomes an input n?

6. Double a number four times
int value = 2;
int i = 1;
while (i <= 4) {
    value *= 2;
    i++;
}

How many iterations are performed?

Part B — Nine more O(1) exercises

7. Add two numbers
int a = 10, b = 20;
int sum = a + b;
System.out.println(sum);
8. Find the square
int number = 6;
int square = number * number;
System.out.println(square);
9. Check even or odd
int number = 17;
if (number % 2 == 0)
    System.out.println("Even");
else
    System.out.println("Odd");
10. Find the larger of two numbers
int a = 25, b = 18;
int largest = (a > b) ? a : b;
System.out.println(largest);
11. Swap two numbers
int a = 10, b = 20;
int temp = a;
a = b;
b = temp;
12. Access a fixed array index
int[] marks = {80, 75, 90, 85};
System.out.println(marks[2]);
13. Get the last array element
int[] marks = {80, 75, 90, 85};
int last = marks[marks.length - 1];
System.out.println(last);
14. Calculate simple interest
double p = 1000, r = 5, t = 2;
double si = (p * r * t) / 100;
System.out.println(si);
15. Find the largest of three numbers
int a = 10, b = 25, c = 15;
int largest = Math.max(a, Math.max(b, c));
System.out.println(largest);

Teacher note: Exercises 1–6 are O(1) because their loop limits are fixed constants. If the loop limit becomes n (for example, i <= n), the loop is generally O(n). Exercise 5 is O(1) only because it calculates factorial of the fixed number 5; factorial of an input n using a loop up to n is O(n). Array access in exercises 12–13 is O(1), even if the array contains many elements.

🐼 Panda’s quick recap

TIME = How many steps / how much work?
SPACE = How much extra memory?
O(1) = fixed growth
O(n) = grows with input size
