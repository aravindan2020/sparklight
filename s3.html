🔎 2. What is Desk Checking?

ELI10: Desk checking means pretending to be the computer. Take sample input, go through the algorithm one step at a time, and write down what happens.
Important: We do not need to execute the Java program. We manually follow the logic using sample values.

Example Student

400 ÷ 5 = 80

4️⃣ Task 4 — Find the Missing or Incorrect Step

Detective question: Is the five-step process enough for a real academic report? Not necessarily. We should check whether the marks are valid before calculating the report.

Potential Missing Step: Validate Marks

For example, if a mark is 150 when the maximum is 100, the system should not blindly calculate the report.

🧠 Corrected Academic Report Algorithm

  1. Start.
  2. Read Student ID.
  3. Read Student Name.
  4. Read marks for five subjects.
  5. Validate each mark.
  6. Calculate Total Marks.
  7. Calculate Average Marks = Total Marks ÷ 5.
  8. Display Student ID and Student Name.
  9. Display the five subject marks.
  10. Display Total Marks and Average Marks.
  11. Stop.
BEGIN

    INPUT StudentID
    INPUT StudentName

    INPUT Mark1, Mark2, Mark3, Mark4, Mark5

    VALIDATE all marks

    Total = Mark1 + Mark2 + Mark3 + Mark4 + Mark5
    Average = Total / 5

    DISPLAY StudentID
    DISPLAY StudentName
    DISPLAY Mark1, Mark2, Mark3, Mark4, Mark5
    DISPLAY Total
    DISPLAY Average

END

🧪 Quick Student Challenge

1. Why do we use stepwise refinement?

To break a large problem into smaller, easier-to-understand and easier-to-implement modules.

2. What does a trace table help us find?

It helps us follow variable values step by step and identify incorrect processing logic.

3. What happens if we calculate Average before Total?

The average calculation may use an unavailable or incorrect total. Total should be calculated first.

4. A mark is 120 out of 100. What should UniFlow do?

Reject or flag the invalid mark before calculating the total and average.
