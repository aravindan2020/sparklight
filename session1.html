01 · Programming

Why do we need programming?

When a university handles thousands of applications, notebooks and paper become slow, difficult to search, and easy to misplace. A program handles repeated work accurately and quickly.

🗂️

⚡

🛡️

03 · Problem-solving method

Computational Thinking

Computational thinking is a structured way of solving problems so that a computer can help us. It has four connected components.

01

Decomposition

Break a large, complex problem into smaller and manageable parts.

UniFlow example: divide the system into Admission, Attendance, Examination, and Reports.

ASK: Can we build the complete system in one day?
02

Pattern Recognition

Look for similarities and common features among problems or data.

UniFlow example: every student has common details such as Student ID, Name, and Department.

ASK: What details are common to every student?
03

Abstraction

Keep only the information that is important for solving the problem; ignore irrelevant details.

UniFlow example: admission needs academic and contact details, not a student's favourite movie.

ASK: Which information is actually necessary?
04

Algorithmic Thinking

Arrange instructions in a clear, logical order to achieve an outcome.

UniFlow example: receive form → validate details → store record → generate admission number.

ASK: What should happen first?
04 · Program model

IPO: Input → Process → Output

Every program takes some data, works on that data, and produces a useful result. This is the IPO model.

Input

  • Student ID
  • Student Name
  • Department
  • Mobile Number

Process

  • Validate Student ID
  • Validate Mobile Number
  • Check required fields
  • Store student information
  • Generate admission record

Output

  • Admission confirmation
  • Student details
  • Registration successful
  • Admission number

Remember: Input is what the user gives, Process is what the program does, and Output is the result the user receives.
